# SymbolPicker: Modifiers Reference Guide

This document provides a technical breakdown of all modifiers available for `SymbolPicker`. These modifiers can be applied to a `SymbolPicker` instance or to the `.symbolPicker()` View extension.

---

## 1. Core Modifiers
These modifiers affect the fundamental behavior and asset types available in the picker.

### `spDisplayStyle(_ style: SPDisplayStyle)`
- **How it works**: Updates the `displayStyle` property in the configuration, which components use to determine their layout (e.g., floating vs. fixed).
- **Available**: iOS 16.4+, macOS 14.0+, visionOS 26.0+, tvOS 16.4+, watchOS 9.4+.
- **When not available**: On OS versions below the specified requirements, it may not have any visual effect as components might lack the corresponding adaptive logic.

### `spSymbolsVariant(_ variant: SPSymbol.Variant)`
- **How it works**: Changes the rendering variant (e.g., `.filled`, `.monochrome`) for SF Symbols.
- **Available**: All platforms.
- **Note**: Only affects the "Symbols" page. Emojis and custom images are unaffected.

### `spAllowSearching(_ condition: Bool)`
- **How it works**: Toggles the visibility of the search bar and the `.searchable` integration.
- **Available**: All platforms.

### `spPageTypes(_ types: [SPPageType], defaultType: SPPageType)`
- **How it works**: Filters the `allowedPageTypes` array and sets the initial `pageType`.
- **Available**: All platforms.
- **Limitations**: The `.image` page type is only available on iOS 16.0+, macOS 14.0+, and visionOS 26.0+.

---

## 2. Component Layout Modifiers

### `spInsetedViews(replaceDefaults: Bool, views: () -> [SPInsetedView])`
- **How it works**: Appends or replaces views in the `insetViewsConfiguration`. It uses a `@SPInsetedViewBuilder` to collect multiple views.
- **Available**: All platforms.
- **How it works (Internal)**: It wraps the existing configuration closure, allowing for incremental updates (chaining multiple `spInsetedViews` calls).

### `spSpacing(content: () -> [SPSpacing])`
- **How it works**: Overrides default spacing values for specific components (e.g., `.topBar`, `.grid`).
- **Available**: All platforms.

---

## 3. SPColorPicker Modifiers
Modifiers prefixed with `spColorPicker` specifically target the color selection component.

- **`spColorPickerEnabled(_ value: Bool)`**
  - **Works by**: Updating the internal configuration's enablement flag.
  - **Note**: If disabled, the entire color picker row/grid is removed from the UI.
- **`spColorPickerColors(_ colors: [CKColor])`**
  - **Works by**: Replacing the default palette with a custom list of `CKColor` objects.
- **`spColorPickerLayout(_ type: Direction, spacing: CGFloat?)`**
  - **Works by**: Setting the axis (`.horizontal` for rows, `.vertical` for columns) and item spacing.
- **`spColorPickerSupportsOpacity(_ value: Bool)`**
  - **Works by**: Showing/hiding the `OpacitySlider` component within the picker.
- **`spColorPickerSupportsCustomColor(_ value: Bool)`**
  - **Works by**: Enabling the integration with the system color well (on supported platforms).

---

## 4. SPOptionList Modifiers
These affect the appearance of the main asset grid and its individual cells.

- **`spOptionListCornerRadiusFactor(_ value: CGFloat)`**
  - **How it works**: A multiplier applied to the base corner radius of each asset cell.
- **`spOptionListInnerPaddingFactor(_ value: CGFloat)`**
  - **How it works**: Adjusts the padding between the cell border and the icon/emoji.
- **Color Overrides (`Foreground` & `Background`)**
  - **States**: Normal, `.Selected`, `.Focused`, `.Pressed`.
  - **How it works**: These modifiers update the `SPOptionListConfiguration`, which the `SPOptionList` cell views read to apply conditional styling.

---

## 5. SPPresentation Modifiers
These modifiers control how the picker is presented when using the `.symbolPicker()` extension.

- **`spPresentationType(_ value: DisplayType)`**
  - **Options**: `.sheet`, `.fullScreenCover`, `.popover`, `.default`.
- **`spPresentationCornerRadius(_ value: CGFloat)`**
  - **Availability**: Limited to platforms supporting sheet customization (iOS 16.4+, visionOS).
- **`spPresentationDragIndicator(_ value: Visibility)`**
  - **Availability**: Standard sheets on iOS/visionOS.
- **`spPresentationDents(_ dents: Set<PresentationDents>)`**
  - **How it works**: Maps to SwiftUI's `.presentationDetents()`.
  - **Options**: `.medium`, `.large`, `.fraction(Double)`, `.height(CGFloat)`.

---

## 6. SPSelectionPreview Modifiers (Advanced UI)
These modifiers enable high-end visual effects for the selection preview.

- **`spSelectionPreviewCornerRadiusFactor(_ value: CGFloat)`**
  - **Available**: All platforms where a preview is shown.
- **`spSelectionPreviewCalculateOffset` & `spSelectionPreviewCalculateScale`**
  - **How it works**: These accept closures that receive `ScrollGeometry` (iOS 26+). They allow the preview to move or resize dynamically as the user scrolls the asset grid.
  - **Available ONLY on**: iOS 26.0+, macOS 26.0+, tvOS 26.0+, visionOS 26.0+, watchOS 26.0+.
  - **Requirements**: Requires Swift 6.0 compiler.
  - **When not available**: On older OS versions, these modifiers are ignored, and the preview remains static or follows default platform behavior.
