# SymbolPicker: The Complete Reference Guide

This document provides an exhaustive reference for the `SymbolPicker` struct, including its architectural design, every initializer variant, and a detailed breakdown of all customization modifiers.

---

## 1. Architectural Overview

`SymbolPicker` is a platform-agnostic, generic SwiftUI `View` designed for selecting visual assets (SF Symbols, Emojis, and custom Images). It leverages a configuration-driven approach to maintain consistency across platforms while allowing for deep customization.

### Generic Type Parameters
- `DataAsset`: Must conform to `SPDataAsset`. It defines the type of items the picker can browse (usually `SPSymbol`, `SPEmoji`, or `SPImage`).
- `Configuration`: Must conform to `SymbolPickerConfiguration`. It dictates the visual style, layout, and behavior of all internal components.

### Core Internal State
The picker maintains several `@State` and `@Binding` properties to manage the user interface:
- `selection`: `Binding<SPSelection<DataAsset>>` - The primary data source/target.
- `pageType`: `SPPageType` - Tracks the currently active category (e.g., `.symbol`).
- `searchText`: `String` - Stores the current search query.
- `hasAppeared`: `Bool` - Ensures initial setup logic only runs once.
- `style`: `Configuration` - The active configuration instance.

## 2. Initializers (Exhaustive List)

`SymbolPicker` provides specialized initializers for various common use cases, simplifying the binding process for different data types.

### Base Initializers
```swift
// Generic initialization with a full SPSelection binding.
public init(selection: Binding<SPSelection<DataAsset>>, configuration: Configuration)

// Generic initialization with an optional SPSelection binding.
public init(selection: Binding<SPSelection<DataAsset>?>, configuration: Configuration)
```

### SF Symbol Specialized Initializers
These initializers fix `DataAsset` to `SPSymbol` and automatically handle string/color conversions.

#### Basic (No Color Selection)
```swift
public init(systemImage: Binding<String>, configuration: Configuration)
public init(systemImage: Binding<String?>, configuration: Configuration)
```

#### With `CKColor` (ColorKit)
```swift
public init(systemImage: Binding<String>, ckColor: Binding<CKColor>, configuration: Configuration)
public init(systemImage: Binding<String?>, ckColor: Binding<CKColor>, configuration: Configuration)
```

#### With SwiftUI `Color`
```swift
public init(systemImage: Binding<String>, color: Binding<Color>, configuration: Configuration)
public init(systemImage: Binding<String?>, color: Binding<Color>, configuration: Configuration)
```

#### With RGB Values (`[Double]`)
Useful for persisting colors as raw arrays (R, G, B, A).
```swift
public init(systemImage: Binding<String>, colorValues: Binding<[Double]>, configuration: Configuration)
public init(systemImage: Binding<String?>, colorValues: Binding<[Double]>, configuration: Configuration)
```

### Emoji Specialized Initializers
These initializers fix `DataAsset` to `SPSymbol` (acting as a container) but focus on `SPEmoji` selection.

```swift

public init(emoji: Binding<SPEmoji?>, colorValues: Binding<[Double]>, configuration: Configuration)
```

## 3. The `body` Property and Internal Workflow

The `body` property is responsible for assembling the modular components based on the active platform and configuration.

### Workflow:
1.  **Container Wrapping**: The `viewContainer` function wraps the content in a `NavigationStack` (iOS 16+), `NavigationView` (older), or directly returns the view (other platforms).
2.  **Core Component**: `SPOptionList` is initialized with the selection binding. This is the main grid that displays the assets.
3.  **Toolbar Placement**: Modifiers are applied to add toolbars. The configuration defines which views (like close buttons, page pickers, or color pickers) appear in which toolbar slots (`.topBarTrailing`, `.bottomBar`, etc.).
4.  **Modern Search Integration**: On iOS 26+, it uses the `.searchable` modifier with `toolbarPrincipal` placement for a modern look.
5.  **Environment Propagation**: The picker injects its entire state into the environment:
    - `.spSearchText`: The binding for searching.
    - `.spSymbolVariant`: The current SF Symbol variant (filled, outlined, etc.).
    - `.spPageType`: The currently active asset category.
    - `.spAllowedPageTypes`: The list of enabled categories.
    - `.spSelection`: The selection protocol for child views to communicate.
    - `.symbolPickerStyle`: The active configuration object.

## 4. Customization Modifiers (Extensive Reference)

These modifiers can be applied to `SymbolPicker` or the `.symbolPicker()` presentation extension.

### 4.1. Core Behavior Modifiers

- **`spDisplayStyle(_ style: SPDisplayStyle)`**
  - **Purpose**: Changes the overall layout strategy.
  - **Options**: `.compact` (modern, floating elements), `.detail` (classic sidebar/list), `.full` (maximized content).
  - **Default**: `.compact` on iOS 26+, `.detail` otherwise.

- **`spSymbolsVariant(_ variant: SPSymbol.Variant)`**
  - **Purpose**: Sets the rendering style for SF Symbols.
  - **Options**: `.monochrome`, `.hierarchical`, `.palette`, `.multicolor`, `.filled`, `.outlined`.
  - **Default**: `.filled`.

- **`spAllowSearching(_ condition: Bool)`**
  - **Purpose**: Enables or disables the search functionality.
  - **Default**: `true`.

- **`spPageTypes(_ types: [SPPageType], defaultType: SPPageType)`**
  - **Purpose**: Restricts which categories (Symbols, Emojis, Images) are available.
  - **Default**: All cases available; defaults to `.symbol`.

### 4.2. Inseted Views & Spacing

- **`spInsetedViews(replaceDefaults: Bool, views: () -> [SPInsetedView])`**
  - **Purpose**: Injects custom SwiftUI views into predefined "safe area" or "toolbar" slots.
  - **Parameter `replaceDefaults`**: If `true`, existing default views (like the preview) in the targeted placement are removed.

- **`spSpacing(content: () -> [SPSpacing])`**
  - **Purpose**: Adjusts the vertical or horizontal spacing between main layout blocks (e.g., between the search bar and the grid).

### 4.3. Color Picker (`SPColorPicker`)

- **`spColorPickerEnabled(_ value: Bool)`**: Globally enables/disables the color selection interface.
- **`spColorPickerColors(_ colors: [CKColor])`**: Sets the palette of predefined colors.
- **`spColorPickerLayout(_ type: Direction, spacing: CGFloat?)`**: Sets orientation (`.horizontal` or `.vertical`) and spacing.
- **`spColorPickerSupportsOpacity(_ value: Bool)`**: Shows/hides the opacity slider.
- **`spColorPickerSupportsCustomColor(_ value: Bool)`**: Enables the system color well for arbitrary color selection.

### 4.4. Option List (`SPOptionList`)

- **`spOptionListCornerRadiusFactor(_ value: CGFloat)`**: Multiplier for the item cell corner radius.
- **`spOptionListInnerPaddingFactor(_ value: CGFloat)`**: Adjusts padding inside each asset cell.
- **Color Overrides**:
  - `spOptionListForeground(_ value: Color)`
  - `spOptionListForegroundSelected(_ value: Color)`
  - `spOptionListBackground(_ value: Color)`
  - `spOptionListBackgroundSelected(_ value: Color)`
  - (Also supports `.Focused` and `.Pressed` states).

### 4.5. Presentation (`SPPresentationConfiguration`)

- **`spPresentationType(_ value: DisplayType)`**: Sets presentation style (`.sheet`, `.fullScreenCover`, `.popover`).
- **`spPresentationCornerRadius(_ value: CGFloat)`**: Sets the sheet's corner radius (iOS 16+).
- **`spPresentationDragIndicator(_ value: Visibility)`**: Shows/hides the grabber at the top of the sheet.
- **`spPresentationBackgroundColor(_ value: Color)`**: Sets the background color of the entire picker surface.
- **Interaction**:
  - `spPresentationContentInteraction(_ value: ContentInteraction)`: Sets whether the content scrolls or expands the sheet.
  - `spPresentationBackgroundInteraction(_ value: BackgroundInteraction)`: Allows interacting with the view *behind* the sheet.
  - `spPresentationDents(_ dents: Set<PresentationDents>)`: Configures sheet detents (e.g., `.medium`, `.large`).

### 4.6. Selection Preview (`SPSelectionPreview`)

- **`spSelectionPreviewCornerRadiusFactor(_ value: CGFloat)`**: Corner radius of the preview card.
- **Advanced Scrolling Effects (iOS 26+ / visionOS 26+)**:
  - `spSelectionPreviewCalculateOffset(_ closure: (ScrollGeometry) -> CGFloat)`: Dynamically move the preview vertically as the user scrolls the grid.
  - `spSelectionPreviewCalculateScale(_ closure: (ScrollGeometry) -> CGFloat)`: Dynamically scale the preview based on scroll position.

## 5. SwiftUI View Extensions (`.symbolPicker`)

The package extends `View` to allow easy presentation of the picker.

### Standard Sheet Usage
```swift
Text("Select an icon")
    .symbolPicker(
        isPresented: $isPresented,
        selection: $selection,
        configuration: MyCustomConfig()
    )
```

The `.symbolPicker` modifier has over 20 overloaded versions matching the initializers of the `SymbolPicker` struct, allowing you to bind directly to `Strings`, `Colors`, and `Images` without manually managing an `SPSelection` object.
