# ``SymbolPicker/SPInsetedView/Placement/toolbarBottomTralling``

@Metadata {
    @SupportedLanguage(swift)

    @Available(watchOS, introduced: "10.0")
    @DocumentationExtension(mergeBehavior: override)

Placement at the trailing edge of the bottom toolbar.

> Important: This placement is not intended for iOS use. While it is technically available for compatibility, it is primarily designed for use on **watchOS**.

## Overview

When set to `.toolbarBottomTralling`, the inset view is placed at the trailing edge (right for LTR languages) of the bottom toolbar. This is a common location for primary actions at the bottom of the interface.

### Availability
This placement is available on both **iOS** and **watchOS**.

### Use Case
Ideal for a primary confirmation button or a "Next" action at the bottom-right of the picker interface.
