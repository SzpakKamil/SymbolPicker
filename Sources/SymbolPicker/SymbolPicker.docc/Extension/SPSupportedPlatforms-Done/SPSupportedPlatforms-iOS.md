# ``SymbolPicker/SPSupportedPlatforms/iOS(_:)``

@Metadata {
    @SupportedLanguage(swift)
    @Available(iOS, introduced: "15.0")
    @DocumentationExtension(mergeBehavior: override)
}

The iOS platform with an optional version.

## Overview

The `iOS` case represents Apple's mobile platform. It stores an optional integer for the major OS version, such as 15 or 17. This information allows the library to perform version-specific feature detection.
