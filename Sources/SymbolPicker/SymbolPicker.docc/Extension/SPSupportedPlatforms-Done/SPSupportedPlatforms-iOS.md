# ``SymbolPicker/SPSupportedPlatforms/iOS(_:)``

@Metadata {
    @SupportedLanguage(swift)
    @Available(iOS, introduced: "15.0")
    @DocumentationExtension(mergeBehavior: override)
}

The iOS platform with an optional version number.

## Overview

The `iOS` case represents the Apple mobile platform. It can store an optional integer representing the major OS version (e.g., 15, 16, 17), which allows the library to perform version-specific feature detection.
