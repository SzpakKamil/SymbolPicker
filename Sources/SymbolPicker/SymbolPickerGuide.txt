# SymbolPicker: Views & Components Guide

This guide details the core UI components of the `SymbolPicker` package. These views are designed to be modular, platform-adaptive, and highly customizable through the `SymbolPickerStyle` environment.

**File Location**: `/Users/kamilszpak/Desktop/Projects/Swift/Packages/SymbolPicker/SymbolPickerGuide.txt`

---

## 1. SPOptionList
`SPOptionList` is the primary grid/list view responsible for displaying data assets (Symbols, Emojis, or Images). It handles layout, selection state, and the display of skin tone pickers for emojis.

### Generic Usage
`SPOptionList` is a generic view that accepts any type conforming to `SPDataAsset`.
```swift
SPOptionList(selection: $selection)
```

### Key Features
- **Dynamic Grid Layout**: Automatically calculates column count based on the available width and the current dynamic type size, ensuring accessibility compliance.
- **Sectioned Display**: Organizes assets into sections (e.g., by category) for easier navigation.
- **Skin Tone Support**: On supported platforms, long-pressing an emoji cell triggers a skin tone selector (or a sheet on watchOS/tvOS).
- **Selection Handling**: Updates the provided `Binding<SPSelection<DataAsset>>` when an item is tapped.

## 2. SPColorPicker
`SPColorPicker` provides a unified interface for selecting colors to tint symbols. It supports predefined palettes, grid/row layouts, and a custom color picker integration.

### Usage
```swift
SPColorPicker()
```
*Note: The color picker will only render if `spAllowsColorSelection` is true and a valid `SPColorPickerConfiguration` is present in the style.*

---

## 3. SPPagePicker
`SPPagePicker` is the segmented control or tab bar that allows users to switch between different asset types (e.g., Symbols vs. Emojis).

### Usage
```swift
SPPagePicker()
```

## 4. SPSearchBar
`SPSearchBar` is a wrapper around the `SearchBar` package, customized for the `SymbolPicker` context. It handles search text binding and platform-specific styling.

## 6. SPSelectionPreview
`SPSelectionPreview` is a specialized view that provides a high-fidelity preview of the currently selected asset. It dynamically updates to reflect changes in selection, color tint, and variant style.

### Usage
```swift
SPSelectionPreview()
```

### Key Features
- **Adaptive Rendering**: Automatically switches its rendering logic based on the selected asset type (Symbol, Emoji, or Image).
- **Color Awareness**: Applies the selected tint color to symbols. It uses intelligent luminance checking to ensure high contrast between the icon and its background (e.g., switching to white text on dark backgrounds).
- **Visual Effects**: 
  - **iOS 26+ / visionOS 26+**: Supports dynamic scaling and vertical offsets based on scroll geometry (via `spPreviewCalculateScale` and `spPreviewCalculateOffset`).
  - **watchOS**: Renders as a circular preview with optional glass effects on modern versions.
  - **tvOS**: Focusable and scales up when highlighted.
- **Shadows and Gradients**: Applies subtle shadows and linear gradients to the preview background for a modern, depth-aware aesthetic.

### Inset Helper
The `asInsetView()` method provides a pre-configured ``SymbolPicker/SPInsetedView`` wrapper:
- **iOS/macOS/visionOS**: Typically pinned to the `safeAreaTop`.
- **watchOS**: Positioned in the `toolbarBottomTralling`.
- **tvOS**: Integrated into the scroll content.

The preview only displays when `isContentAvailable()` returns true for the current selection.
