# SymbolPicker: Views & Components Guide

This guide details the core UI components of the `SymbolPicker` package. These views are designed to be modular, platform-adaptive, and highly customizable through the `SymbolPickerStyle` environment.

## 1. SPOptionList
`SPOptionList` is the primary grid/list view responsible for displaying data assets (Symbols, Emojis, or Images). It handles layout, selection state, and the display of skin tone pickers for emojis.

### Generic Usage
`SPOptionList` is a generic view that accepts any type conforming to `SPDataAsset`.
```swift
SPOptionList(selection: $selection)
```

### Key Features
- **Dynamic Grid Layout**: Automatically calculates column count based on the available width and the current dynamic type size, ensuring accessibility compliance.
- **Sectioned Display**: Organizes assets into sections (e.g., by category) for easier navigation.
- **Skin Tone Support**: On supported platforms, long-pressing an emoji cell triggers a skin tone selector (or a sheet on watchOS/tvOS).
- **Selection Handling**: Updates the provided `Binding<SPSelection<DataAsset>>` when an item is tapped.

### Customization
- **Spacing**: Controlled via `SymbolPickerStyle.spacings`.
- **Item Size**: Adaptive based on the environment's `dynamicTypeSize`.

## 2. SPColorPicker
`SPColorPicker` provides a unified interface for selecting colors to tint symbols. It supports predefined palettes, grid/row layouts, and a custom color picker integration.

### Usage
```swift
SPColorPicker()
```
*Note: The color picker will only render if `spAllowsColorSelection` is true and a valid `SPColorPickerConfiguration` is present in the style.*

### Configuration
The appearance and behavior are controlled via `SPColorPickerConfiguration`:
- **Layout Types**: `.grid` (multi-row) or `.row` (single horizontal scroll).
- **Custom Colors**: Enables a "rainbow" cell that opens the system color picker.
- **Spacing & Sizing**: customizable via the configuration object.

### Platform Specifics
- **iOS/macOS/visionOS**: Renders within a glass-effect container on supported versions.
- **watchOS**: Presents as a button that opens a dedicated color selection sheet.
- **tvOS**: Optimized focus-based navigation.

## 3. SPPagePicker
`SPPagePicker` is the segmented control or tab bar that allows users to switch between different asset types (e.g., Symbols vs. Emojis).

### Usage
```swift
SPPagePicker()
```

### Behavior
- **Automatic Filtering**: Only displays segments for page types enabled in `spAllowedPageTypes`.
- **Hiding**: If only one page type is allowed, the picker automatically hides itself to save space.
- **Platform Adaptation**:
  - **iOS/visionOS**: Uses a segmented control style with platform-appropriate padding.
  - **watchOS**: Renders as a toggle button to switch between the two available modes.
  - **macOS/tvOS**: Uses specialized spacing and focus effects for better readability.

## 4. SPSearchBar
`SPSearchBar` is a wrapper around the `SearchBar` package, customized for the `SymbolPicker` context. It handles search text binding and platform-specific styling.

### Usage
```swift
SPSearchBar()
```

### Features
- **Context-Aware Prompt**: Automatically changes placeholder text based on the active page (e.g., "Search Symbols" vs. "Search Emojis").
- **Adaptive Styling**:
  - **iOS/visionOS**: Uses a capsule style with blurred backgrounds.
  - **macOS**: Uses a rounded rect style.
  - **tvOS**: Optimized for focus and remote interaction.
- **Glass Effects**: On supported platforms (iOS 26+), integrates with system glass materials.

### Inset Helper
The `asInsetView()` method wraps the search bar in an `SPInsetedView`, positioning it correctly within the scrollable content area (e.g., pinned to the top or bottom safe area).

## 5. SPDismissButton
`SPDismissButton` is a standardized close button used within the picker's presentation.

### Usage
```swift
SPDismissButton()
```

### Behavior
- **Action**: Triggers the SwiftUI `dismiss` environment action.
- **Styling**:
  - **iOS 26+**: Uses a glass button style with a circle border.
  - **Legacy iOS**: Falls back to a standard `xmark.circle.fill` icon.
  - **macOS/watchOS**: Standard text or icon button.
- **Localization**: Uses `SPTranslation.Close` for accessibility labels and button titles.
